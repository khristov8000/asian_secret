# EN/RU Translations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate complete English and Russian versions of asiansecret.bg under `/en` and `/ru`, fully wired into the existing SEO setup, without altering any existing Bulgarian URL.

**Architecture:** `tools/seo-build.mjs` already generates 27 static pages from `assets/data.js` plus the root `.html` files used as templates. This plan adds a locale dimension to that build. Bulgarian markup keeps its text inline behind a `data-t` key and is never rendered from locale data; only `/en` and `/ru` are generated from JSON. JavaScript-built UI (the whole checkout) reads a `T` dictionary injected per page.

**Tech Stack:** Node 18+ ESM (no dependencies — the repo has none), static HTML/CSS/JS, Apache `.htaccess`, PHP 8 for the order endpoint (not modified).

**Spec:** `docs/superpowers/specs/2026-08-23-i18n-en-ru-design.md`

## Global Constraints

Copied verbatim from the spec. Every task's requirements implicitly include these.

- **Bulgarian does not move.** No `/bg` prefix. No existing URL redirects or changes. `/en` and `/ru` are purely additive.
- **Bulgarian is never rendered from locale data.** A missing key, malformed JSON or build crash must leave the Bulgarian site byte-identical.
- **Never translated:** `slug`, `sku`, `price`, `accent`, `tint`, `cat`, `concerns`, `overlay`, `benefits[].icon`, image paths, and brand names (`Premium Resbro EX`, `Zen no Shizuku`, …). Product slugs are byte-identical in all three languages.
- **Currency is EUR everywhere.** `priceCurrency: EUR`, formatted `29,90 €` — comma decimal separator in all three languages.
- **No language detection.** No `Accept-Language`, no cookie, no `localStorage` for language, no JS redirect. `/` renders Bulgarian on every visit.
- **Canonicals are self-referencing.** `/en/products` → `/en/products`. Never cross-language.
- **`x-default` always points at Bulgarian.**
- **`api/_emails.php` and `api/order.php` are not modified.**
- **Path segments:** EN uses `product` / `category`; RU reuses `produkt` / `kategoria`; BG unchanged (`produkt` / `kategoria`).
- **No new runtime dependencies.** No npm install. Node built-ins only.
- **Comments in source files are written in Bulgarian**, matching the existing codebase convention.
- **`DESIGN.md` §356 constraint:** below 760px the header fits exactly three controls at 390px. The switcher must not become a fourth.

```js
/* Единствената карта на адресите. Build-ът, hreflang таговете, sitemap-ът и
   превключвателят на езици четат оттук - затова не могат да се разминат. */
export const SITE = 'https://asiansecret.bg';
export const LANGS = ['bg', 'en', 'ru'];

/* Пътните сегменти. Българският и руският споделят транслитерацията:
   "produkt" и "kategoria" се четат и като продукт/категория на руски. */
export const SEG = {
  bg: { product: 'produkt', category: 'kategoria' },
  en: { product: 'product', category: 'category' },
  ru: { product: 'produkt', category: 'kategoria' }
};

/* Българският няма представка - старите адреси остават непокътнати. */
const prefix = lang => (lang === 'bg' ? '' : '/' + lang);

export function urlFor(page, lang, param) {
  const p = prefix(lang);
  switch (page) {
    case 'home': return p + '/';
    case 'products': return p + '/products';
    case 'about': return p + '/about';
    case 'contact': return p + '/contact';
    case 'cart': return p + '/cart';
    case 'product': return p + '/' + SEG[lang].product + '/' + param + '/';
    case 'category': return p + '/' + SEG[lang].category + '/' + param + '/';
    default: throw new Error('unknown page: ' + page);
  }
}

/* Адрес -> файл на диска. Чистите адреси се поднасят от .htaccess, затова
   /en/products идва от en/products.html, а /en/ - от en/index.html. */
export function fileFor(page, lang, param) {
  const u = urlFor(page, lang, param);
  const rel = u.replace(/^\//, '');
  return u.endsWith('/') ? rel + 'index.html' : rel + '.html';
}

/* Пълен набор от четири записа, винаги в един и същи ред, с включен
   самопосочващ се запис - Google изхвърля еднопосочните набори. */
export function alternatesFor(page, param) {
  const bg = SITE + urlFor(page, 'bg', param);
  return [
    { lang: 'bg', url: bg },
    { lang: 'en', url: SITE + urlFor(page, 'en', param) },
    { lang: 'ru', url: SITE + urlFor(page, 'ru', param) },
    { lang: 'x-default', url: bg }
  ];
}
```

### Task 2: Key the markup with `data-t`

Annotate every translatable element in the six templates. Bulgarian text stays inline; the key is what `/en` and `/ru` look up. Nothing renders differently yet — this task is pure annotation plus the extraction tool that proves the annotation is complete.

**Files:**
- Modify: `index.html`, `products.html`, `product.html`, `cart.html`, `about.html`, `contact.html`
- Create: `tools/i18n-extract.mjs`
- Create: `i18n/ui.en.json`, `i18n/ui.ru.json`

**Interfaces:**
- Consumes: nothing
- Produces:
  - `data-t="<section>.<name>"` attributes in the six templates. Key namespaces: `nav.*`, `hero.*`, `home.*`, `cat.*`, `shop.*`, `product.*`, `cart.*`, `checkout.*`, `about.*`, `contact.*`, `foot.*`, `meta.*`
  - `i18n/ui.{en,ru}.json` — flat `{ "key": "translated text" }`. A key whose value is `null` is untranslated and falls back to Bulgarian with a warning.
  - `tools/i18n-extract.mjs` — rescans templates and merges new keys into the locale files as `null` without disturbing existing translations.

- [ ] **Step 1: Add `data-t` to every translatable element**

Rules for annotating:

- Annotate the element that owns the text, not a wrapper. `<h2>Разгледай <em>по категория</em></h2>` becomes `<h2 data-t="home.catsTitle">Разгледай <em>по категория</em></h2>` and the locale value carries the same inline `<em>` markup.
- Attributes that hold user-visible text get their own key with an `@` suffix: `<img alt="…">` → `data-t-alt="hero.imageAlt"`; likewise `data-t-placeholder`, `data-t-title`, `data-t-aria-label`.
- `<title>` and `<meta name="description">` are keyed `meta.<page>.title` / `meta.<page>.desc`. Generated product and category pages get their head from `seo-build.mjs`, so those need no key here.
- Do **not** annotate: brand names, `Asian Secret`, prices, SKUs, or the `€` sign.

Example, `index.html:44`:

```html
<nav class="main" id="mainnav"><a href="/" class="active" data-t="nav.home">Начало</a><a href="/products" data-t="nav.products">Продукти</a><a href="/about" data-t="nav.about">За нас</a><a href="/contact" data-t="nav.contact">Контакти</a></nav>
```

- [ ] **Step 2: Write the extraction tool**

Create `tools/i18n-extract.mjs`:

```js
/* Събира ключовете от шаблоните и ги слива в i18n/ui.<lang>.json.
   Новите ключове влизат с null - това е списъкът за превод. Съществуващите
   преводи не се пипат. Пуска се с: node tools/i18n-extract.mjs */
import fs from 'fs';
import path from 'path';

const root = process.cwd();
const TEMPLATES = ['index.html', 'products.html', 'product.html',
                   'cart.html', 'about.html', 'contact.html'];

/* Ключовете идват както от data-t, така и от data-t-<атрибут>. */
const KEY_RE = /\sdata-t(?:-[\w-]+)?="([^"]+)"/g;

export function keysFromTemplates() {
  const keys = new Set();
  for (const f of TEMPLATES) {
    const html = fs.readFileSync(path.join(root, f), 'utf8');
    for (const m of html.matchAll(KEY_RE)) keys.add(m[1]);
  }
  return [...keys].sort();
}

if (import.meta.filename === process.argv[1]) {
  const keys = keysFromTemplates();
  fs.mkdirSync(path.join(root, 'i18n'), { recursive: true });
  for (const lang of ['en', 'ru']) {
    const p = path.join(root, 'i18n', 'ui.' + lang + '.json');
    const cur = fs.existsSync(p) ? JSON.parse(fs.readFileSync(p, 'utf8')) : {};
    const out = {};
    let added = 0;
    for (const k of keys) {
      out[k] = Object.prototype.hasOwnProperty.call(cur, k) ? cur[k] : null;
      if (out[k] === null && !(k in cur)) added++;
    }
    /* Ключове, които вече не се срещат в шаблоните, отпадат сами. */
    fs.writeFileSync(p, JSON.stringify(out, null, 1) + '\n');
    const done = keys.filter(k => out[k] !== null).length;
    console.log(`ui.${lang}.json: ${keys.length} ключа, ${done} преведени, ${added} нови`);
  }
}
```

Plural-sensitive strings take a count and choose a form. Bulgarian and English are two-form; Russian is three-form (1 / 2-4 / 5+), so the dictionary stores an array and the helper picks:

```js
/* Множествено число: българският и английският имат две форми, руският - три
   (1 продукт / 2-4 продукта / 5+ продуктов). Ключът пази масив. */
function plural(key, n) {
  const forms = I18N.T[key];
  if (!Array.isArray(forms)) return forms || '⟨' + key + '⟩';
  if (I18N.lang !== 'ru') return forms[n === 1 ? 0 : 1];
  const m10 = n % 10, m100 = n % 100;
  if (m10 === 1 && m100 !== 11) return forms[0];
  if (m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14)) return forms[1];
  return forms[2];
}
```

Put `plural` in `assets/shop.js` next to the `T` proxy so all pages share it.

- [ ] **Step 3: Implement `translateProduct`**

Append to `tools/i18n-lib.mjs`:

```js
/* Превежда само текстовите полета. Всичко останало - слъг, цена, цветове,
   имена на икони, пътища до снимки - се пренася непокътнато. Български не
   минава оттук изобщо: източникът му е assets/data.js. */
export function translateProduct(p, lang, dict) {
  if (lang === 'bg') return p;
  const t = dict[p.slug];
  if (!t) return p;

  const out = { ...p };
  if (t.name) out.name = t.name;
  if (t.size) out.size = t.size;
  if (t.short) out.short = t.short;
  if (t.intro) out.intro = t.intro;
  if (t.badges) out.badges = t.badges;

  /* benefits е плосък масив: заглавие, описание, заглавие, описание...
     Иконата стои в оригинала и не се вижда в преводния файл. */
  if (t.benefits) {
    out.benefits = p.benefits.map((b, i) => ({
      ...b,
      t: t.benefits[i * 2] ?? b.t,
      d: t.benefits[i * 2 + 1] ?? b.d
    }));
  }
  if (t.specs) out.specs = { ...p.specs, ...t.specs };

  if (t.story && p.story) {
    out.story = { ...p.story };
    if (t.story.lead) out.story.lead = t.story.lead;
    if (t.story.caps && p.story.images) {
      out.story.images = p.story.images.map((im, i) => ({
        ...im, cap: t.story.caps[i] ?? im.cap
      }));
    }
  }
  return out;
}

/* Категориите и грижите са малки - превеждат се на място по id. */
export function translateList(list, lang, dict) {
  if (lang === 'bg') return list;
  return list.map(x => (dict[x.id] ? { ...x, ...dict[x.id] } : x));
}
```

```js
import { LANGS, SEG, urlFor, fileFor, alternatesFor, translateProduct, translateList, SITE as I18N_SITE } from './i18n-lib.mjs';

const missing = [];   /* [{lang, key, file}] - отчита се в края на build-а */

/* Заменя текста на всеки елемент с data-t и стойността на всеки
   data-t-<атрибут>. Български не минава оттук - шаблонът си е готов. */
function applyLocale(html, lang, ui, file) {
  const look = key => {
    const v = ui[key];
    if (v === null || v === undefined) { missing.push({ lang, key, file }); return null; }
    return v;
  };

  /* Атрибутите първи: инак подмяната на текста може да мести отместванията. */
  html = html.replace(/<([a-z0-9]+)([^>]*?)\sdata-t-([\w-]+)="([^"]+)"([^>]*)>/gi,
    (m, tag, pre, attr, key, post) => {
      const v = look(key);
      if (v === null) return m;
      const whole = pre + post;
      const re = new RegExp('\\s' + attr + '="[^"]*"');
      const rebuilt = re.test(whole) ? whole.replace(re, ' ' + attr + '="' + esc(v) + '"')
                                     : whole + ' ' + attr + '="' + esc(v) + '"';
      return '<' + tag + rebuilt + '>';
    });

  /* После текстът. Стойността може да носи вътрешен маркъп (<em>, <br>),
     затова се вгражда както е - преводните файлове са наши, не чужд вход. */
  html = html.replace(/<([a-z0-9]+)([^>]*\sdata-t="([^"]+)"[^>]*)>([\s\S]*?)<\/\1>/gi,
    (m, tag, attrs, key, inner) => {
      const v = look(key);
      return v === null ? m : '<' + tag + attrs + '>' + v + '</' + tag + '>';
    });

  return html;
}
```

The text replacement matches the element's own closing tag via the `\1` backreference. Elements carrying `data-t` must therefore not nest another element of the same tag name inside them — `<div data-t=…><div>…</div></div>` would match the inner close. Task 2's rule "annotate the element that owns the text, not a wrapper" keeps this safe; the check in Task 11 asserts it.

```js
  for (const c of CATS) pages.push({ page: 'category', lang, param: c.id });
  for (const p of PRODUCTS) pages.push({ page: 'product', lang, param: p.slug });
}

for (const { page, lang, param } of pages) {
  const file = fileFor(page, lang, param);
  if (!fs.existsSync(path.join(root, file))) { bad(`липсва файл ${file}`); continue; }
  const html = read(file);

  /* 1 + 3: пълен и реципрочен набор алтернативи. */
  const want = alternatesFor(page, param);
  for (const a of want) {
    const tag = `hreflang="${a.lang}" href="${a.url}"`;
    if (!html.includes(tag)) bad(`${file}: липсва ${tag}`);
  }
  const count = (html.match(/rel="alternate"\s+hreflang=/g) || []).length;
  if (count !== 4) bad(`${file}: ${count} алтернативи вместо 4`);

  /* 2: всеки алтернативен адрес сочи съществуващ файл. */
  for (const a of want) {
    if (a.lang === 'x-default') continue;
    const f = fileFor(page, a.lang, param);
    if (!fs.existsSync(path.join(root, f))) bad(`${file}: ${a.url} сочи липсващ ${f}`);
  }

  /* 4: каноничният адрес сочи самата страница. */
  const canon = (html.match(/<link rel="canonical" href="([^"]+)"/) || [])[1];
  const self = SITE + urlFor(page, lang, param);
  if (canon !== self) bad(`${file}: canonical ${canon} вместо ${self}`);

  /* 5: нито един ключ не е паднал на български и нито един не е останал сляп. */
  if (/data-t="/.test(html) && lang !== 'bg') bad(`${file}: остатъчен data-t атрибут`);
  if (html.includes('⟨')) bad(`${file}: непопълнен ключ в JS низ`);

  /* 7: кирилица в английските страници е пропуснат низ. */
  if (lang === 'en' && /[Ѐ-ӿ]/.test(html.replace(/<!--[\s\S]*?-->/g, '')))
    bad(`${file}: кирилица в английска страница`);

  /* Езикът на документа. */
  if (!new RegExp(`<html[^>]*lang="${lang}"`).test(html))
    bad(`${file}: <html lang> не е ${lang}`);
}

/* 6: ui.bg.json покрива всеки ключ, търсен от JS. */
const js = read('assets/shop.js') + ['cart.html', 'product.html', 'products.html'].map(read).join('');
const bgUI = JSON.parse(read('i18n/ui.bg.json'));
for (const m of js.matchAll(/T\[['"]([\w.]+)['"]\]/g)) {
  if (!(m[1] in bgUI)) bad(`ui.bg.json: липсва ключ ${m[1]}`);
}

console.log(fail ? `\n${fail} проблема` : `\n${pages.length} страници - всичко наред`);
process.exit(fail ? 1 : 0);
```

Note: check 5's `data-t` assertion is what also catches the nesting hazard from Task 5 Step 1 — a `data-t` element whose content failed to match leaves the attribute behind in the generated output.
