# Asian Secret — уебсайт (BG)

Статичен сайт за **Asian Secret** — японска и азиатска козметика. Работи без сървър: качва се директно в хостинг, GitHub Pages, Netlify или Vercel.

## Страници
| Файл | Страница |
| --- | --- |
| `index.html` | Начало — герой, категории, бестселъри, грижа според нуждата, Instagram |
| `products.html` | Каталог с филтри (категория, нужда, произход) и подредба |
| `product.html?p=<slug>` | Продуктова страница + оригиналния продуктов лист (оверлей) |
| `cart.html` | Количка + данни за доставка + изпращане на поръчката по имейл |
| `about.html` | За бранда, принципи, ритуал, марки |
| `contact.html` | Контакти, форма, доставка и плащане (`#delivery`), ЧЗВ (`#faq`) |

## Файлове
- `assets/site.css` — всички стилове и брандови токени (цветове, типография, радиуси, сенки). Тема **Blossom** — порцеланово бяло, ink черно и роза/сакура; без злато.
- `assets/site-v1-gold.css` — предишната златна тема (резервно копие; не се използва).
- `assets/sakura-branch.png`, `sakura-bloom.png`, `sakura-petal.png` — прозрачни акценти с черешов цвят, изрязани от логото; използват се в героя, вътрешните страници и футъра.
- `assets/data.js` — **каталогът**: 29 продукта с цени, категории, нужди, акцентен цвят и текстове (адаптирани от продуктовите оверлеи).
- `assets/shop.js` — количка (localStorage), продуктови карти, известия.
- `assets/products/` — продуктови снимки. 25 продукта имат изрязана снимка на **прозрачен фон** (`.png`, 1200 px); останалите 4 са `.jpg`. Кой продукт кой формат ползва се определя от `TRANSPARENT_SHOTS` в `assets/data.js` — при добавяне на нов PNG добавете slug-а и там.
- `assets/overlays/` — продуктовите листове/оверлеи (1400 px).
- `assets/logo-as.png`, `assets/favicon.png` — лого AS.

## Какво трябва да проверите преди пускане
1. **Имейл за поръчки.** В съобщението беше посочен `zax12@abv.67` — приех, че е `zax12@abv.bg`. Ако е друг, сменете го на 3 места: `cart.html` (`const ORDER_EMAIL`), `contact.html` (формата) и линковете в контактите/футъра.
2. **Изпращане на поръчки.** Формите използват [FormSubmit](https://formsubmit.co) — без бекенд. При **първата** изпратена поръчка FormSubmit праща имейл за активация на `zax12@abv.bg`; след потвърждението всички следващи поръчки идват директно във вашата поща. Ако изпращането не успее, сайтът показва резервен линк, който отваря готов имейл с цялата поръчка.
3. **Цени.** Цените в `assets/data.js` са **примерни** (в евро, с показване и в лева по фиксирания курс 1,95583). Сменете стойностите `price:` с реалните.
4. **Наличности и продукти.** Каталогът е изграден от папките в GitHub хранилището. 4 продукта (крем за ръце MHY, SPF90+, крем за коса MHY, Phytocotton) нямат отделни продуктови снимки — снимката е изрязана от техния оверлей. Ако имате чисти продуктови снимки, заменете файловете в `assets/products/`.
5. **Доставка.** Цени: 3,90 € до офис, 4,90 € до адрес, безплатна над 60 € — сменете в `cart.html` и `contact.html`.
